How it works

01

Drop a file in

Spreadsheets, CSV, JSON, PDF, Word, PowerPoint — or paste a public link. No account, no sign-up, and no API key to get started.

02

Read the computed evidence

Statistics, correlations with their sample sizes, a data-quality grade and structured evidence — all calculated outright, with no model involved.

03

Add Claude if you want it explained

Optional. Paste an Anthropic key to have the findings written up and to ask follow-up questions — always grounded in the numbers already computed.

Why teams can trust the output

computed, not guessed

Deterministic profiling

Missingness, type consistency, IQR outliers, duplicate rows, and a weighted health grade are calculated in code — the AI reads them, it doesn't invent them.

full-file evidence

Charts that match the numbers

A distribution, frequency or trend chart for every column, a scatter plot behind every correlation, and a correlation matrix — aggregated across the complete file, never inferred from preview rows or generated by a model.

nothing kept

Private by default

No account. Files are parsed in memory and never written to disk. Nothing is saved unless you tick the box that saves it. The code is open — read it.

claim → calculation → rows

Evidence you can audit

Open any finding to see its formula, inclusion rule, excluded-row count, and a bounded excerpt of the exact source rows involved.

baseline → current

Know what actually changed

Compare two files for schema drift, quality movement, mean intervals, and full-distribution shifts—without asking a model to do arithmetic.

uncertainty included

Evidence with statistical boundaries

Mean intervals, Welch tests, Cramér's V, and KS shifts carry sample sizes, p-values, effect sizes, and multiple-testing caveats.

Who it's for

For the teams expected to make a decision from a spreadsheet they did not build.

Finance and revenue teams

You get an export from a system you don't control. Ridge tells you what is actually in it — how complete each column is, what correlates, what looks wrong — before you build anything on top of it.

Operations and strategy

You need a defensible read on a file today, not a notebook and an afternoon. Drop it in, get the numbers, and know which ones rest on enough data to quote.

Data and analytics teams

Profile a handoff before it reaches a warehouse or dashboard. Surface mixed types, missingness, duplicates, outliers, and weak statistical support early.

What happens to your data

Files are never stored

Uploads are parsed in memory and discarded when the request ends. Nothing is written to disk, and there is no database row unless you ask for one.

Saving is a decision you make

History and share links are off until you tick Save this analysis. Untouched, a run leaves nothing behind — and saved runs can be deleted.

Your key is yours

An Anthropic key is optional and kept for the session by default. It travels with your request to Anthropic and is never stored server-side or logged.
