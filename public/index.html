How it works

01

Add your Anthropic key

Stored in your browser's local storage, sent only alongside your own requests. Get one at console.anthropic.com — the server never keeps it.

02

Drop a file or paste a link

Spreadsheets, PDFs, Word, PowerPoint, JSON. Multi-sheet workbooks get a sheet picker; cloud files fetch by URL up to 25 MB.

03

Read, then interrogate

Statistics, correlations, a data-quality grade, charts, and written insights — then ask follow-up questions grounded in the same numbers.

Why it holds up

computed, not guessed

Deterministic profiling

Missingness, type consistency, IQR outliers, duplicate rows, and a weighted health grade are calculated in code — the AI reads them, it doesn't invent them.

schema-enforced

Grounded insights

Claude answers against the computed statistics and quality profile, and its output is constrained to a strict JSON schema — no free-form hallucinated reports.

byok

Private by design

No accounts, no server-side keys, files parsed in memory, immutable share links you create on purpose. The code is open — read it.
